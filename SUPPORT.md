# Support

## Getting Help

Thanks for using `scorecard-api`! Here are some ways to get help:

### Documentation

- [README](README.md) — project overview, endpoints, configuration, and quickstart
- [AGENTS.md](AGENTS.md) — conventions, tooling, and the spec-driven workflow
- [docs/bootstrap.md](docs/bootstrap.md) — original design context
- [docs/acceptance.md](docs/acceptance.md) — end-to-end acceptance runbook
- [docs/upstream-graft.md](docs/upstream-graft.md) — upstream graft map
- [openspec/](openspec/) — specifications and change proposals
- [CONTRIBUTING](CONTRIBUTING.md) — how to contribute

### Issues

If you've found a bug or have a feature request:

1. Search [existing
   issues](https://github.com/uwu-tools/scorecard-api/issues) first
2. If not found, [open a new
   issue](https://github.com/uwu-tools/scorecard-api/issues/new/choose)

### Security Issues

**Please do not report security vulnerabilities through public issues.**

See our [Security Policy](SECURITY.md) for responsible disclosure instructions.

## Response Times

This is an open source project. Response times may vary based on maintainer
availability. We appreciate your patience!

## Support Scope

| Version | Status      | Support Duration |
| ------- | ----------- | ---------------- |
| main    | Pre-release | Latest commit    |

`scorecard-api` is pre-1.0 and under active development; interfaces may change.
Support currently tracks the `main` branch.
